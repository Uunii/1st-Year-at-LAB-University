## 📚 Courses this year

### 🐍 Python Programming
My first real dive into programming. Went from "what's a variable" to building a full app with user authentication, admin roles, and live data from the cloud. Not bad for year one.

### 🌐 Web Basics — HTML & CSS
Learned how the web is actually put together. Made things look decent (mostly).

### ✍️ Professional English
English for the workplace — writing, communicating, presenting. Useful stuff, even if I already spend most of my day in English anyway.

### 🌍 Intercultural Awareness
Honestly one of the most interesting courses. LAB is super international, so learning how to communicate across cultures is actually practical — not just theory.

### 🇫🇮 Finnish 1 & 2
*Hei! Miten menee?*
That's about as far as I got, but hey — it's a start. Finnish is no joke.

## 🏆 Highlight project — Movement App

The big one from 1st year. A Python console app that:

- 🌡️ Pulls live **temperature & humidity** readings from a **ThingSpeak**-connected sensor
- 👤 Has full **user login system** — register, set password, authenticate
- 🔐 **Admin vs regular user** roles — only admins can touch the important stuff
- 📊 Displays the latest sensor readings straight to the console

It's not pretty (it's a console app 😅) but it works, and I built the whole thing myself.
